# 📐 自控 · 线控 复习本

一个**完全本地、纯离线**的《自动控制原理》/《线性控制系统》错题与知识点复习网站。
无需注册、无后端、无云端上传，所有数据都保存在你自己的浏览器里。

两门课在同一个站点内用顶部按钮切换：**自动控制原理 (ac)** 与 **线性控制系统 (lc)**。

在线使用：https://fumoran.github.io/auto-control-review-book/

> 手机上可用浏览器「安装应用 / 添加到主屏幕」，安装后即为全屏应用，
> 断网也能正常复习。

## 主要功能

- **错题库 + 知识点库**双库分离，标签共用；解析与知识点默认折叠
- **科目分区**：自动控制原理（ac）/ 线性控制系统（lc）一键切换，条目的 `subject` 字段决定归属
- 支持粘贴 AI 按固定格式生成的题目**批量导入**
  （`【题目】/【解析】/【知识点】/【代码】/【我的错误答案】/【标签】`，多题用 `===` 分隔）
- KaTeX 公式渲染、**图片上传与压缩**（存 IndexedDB）、导入**去重**提示
- **📐 速查表**（全站共享一张表）：**拉普拉斯变换对**与**状态空间基础式**变换对（31 条）、
  **时域 / 频域 / 状态空间判据**（劳斯、赫尔维茨、奈奎斯特、裕度、能控/能观、极点配置等 17 条）、
  **经典 ↔ 现代 / 连续 ↔ 离散对照**（s↔z、传递函数↔状态空间、根轨迹↔特征值轨迹等 10 组），可搜索
- **📈 绘图**（纯 Canvas，无第三方库）：
  **时域响应**（单位阶跃 / 单位冲激）、**Bode 图**、**奈奎斯特图**（自动给出 P/N/Z 判稳结论）、
  **根轨迹**、**零极点图**（自动判稳）、**卷积图解**（连续 / 离散，带平移动画）等常用控制图形
- **代码高亮**：解析里的 MATLAB / Python 代码块自动识别语言并着色，可一键复制
- **公式快捷插入条**、**学科预设标签**（按 自控 (ac) / 线控 (lc) 分组的常用术语一键打标）
- ⭐ 收藏、多标签交集筛选、背题模式、随机一题、返回顶部、长按多选
- 搜索扩展：`tag:` / `status:` / `star` / `due` / `has:img` / `has:code` 前缀 + 全文关键词
- **图形体验**：剪贴板 / 拖拽粘贴图片、配图编号与排序、卡片大图模式、
  多图**灯箱**（翻页 / 缩放 / 旋转 / 拖动）
- **回收站**（软删除 + 30 天自动清理）、JSON 导出导入、完整备份（含图片）、
  Markdown 导出、打印、**孤儿图片 GC**
- 可自定义**分栏 / 主题 / 密度 / 动效 / 卡片配图大小**，适配手机、平板横屏与桌面
- **AI 识题**（可选）：拍照上传题目，由你自选的 AI 服务商识别并整理成字段，核对后导入；
  也可一键复制**学科化提示词**，拿去任意对话式 AI 里预处理

## 项目结构

- `index.html` — 页面骨架
- `styles.css` — 样式与主题
- `app.js` — 应用逻辑（错题库 / 知识点库 / 交互）
- `lib.js` — 通用工具函数
- `plot.js` — 纯 Canvas 绘图
- `conv.js` — 卷积图解
- `code.js` — 代码高亮
- `transforms.js` — 速查表数据（变换对 / 判据 / 对照，全站共享）
- `sw.js` / `manifest.json` — 离线 PWA（Service Worker + Web App Manifest）
- `vendor/katex/` — KaTeX 公式引擎

## 数据与隐私

除「AI 识题」外，所有内容仅存于浏览器本地（`localStorage` + `IndexedDB`），不上传任何服务器。

「AI 识题」是唯一需要联网的功能：使用它时，**题目图片会发送到你自己选择并配置的
AI 服务商**（API Key 只保存在本机浏览器，不写入备份文件、不进仓库）。不使用该功能
时，应用完全离线可用。

换设备或清理浏览器数据会丢失内容，请**定期使用「导出」备份**。
